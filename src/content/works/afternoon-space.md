## 構成

イントロ（4小節） → A（8小節） → B（8小節） → ブレイク（4小節） → A変奏（8小節） → クライマックス（8小節） → アウトロ（4小節）。44小節で一周し、繰り返します。

和声は Dm9 / G13 / Cmaj9 / A7(b9) / Fmaj9 / Bbmaj9 / Em7 / A7(b9)。各コードを2小節ずつ奏でます。

## 音を変える

コード冒頭の `set` で、楽器ごとの音量、スウィング、残響を調整できます。内蔵音源のみを使っています。
