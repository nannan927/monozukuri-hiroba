# tomooooo.com 移行記録

2026-11-05に、所有者の依頼により公開サイトを読み取り、改訂版へ移行。

## 移行対象

- サイトマップ掲載の43ページを取得し、原本HTMLを隣の `../../migration-source-tomooooo/` に保存。
- ブログ記事36件をMarkdown化。タイトル・掲載日・本文・元の分類を保持。
- 元サイトで「日記」と分類されていた1件は `/diary/`、文学1件を含む残り35件は `/writing/`。文学は `/literature/` からも閲覧可能。
- 同日の記事は元サイトの並び順を保持。
- 「アクターネットワーク」「環境への」は元サイトでも本文が空欄。その状態を明示して保存。
- `/creative/`: note、ノベルアップ＋への元のリンク。
- `/development/`: GitHubへの元のリンク。
- `/diary/`: gooブログへの元のリンク。
- 元サイト内の36記事と分類ページ等に対応する42個の旧パスを、新しいサイト側で転送。

## 対象外・変更していないもの

- note、ノベルアップ＋、gooブログ、GitHub内の投稿やリポジトリは複製せず、元のリンクを保存。
- `/about/` に残っていたJimdoの未編集テンプレート文・Jimdoの広告は移植していない。
- 調査した36記事内には画像・音声・動画はなかった。Jimdoの共通背景画像やプロバイダーのロゴは新デザインへ移していない。
- 元サイトのホスティング、DNS、ドメインは変更していない。新サイト側の旧パス転送は、元ドメインへのアクセスを転送するものではない。
- 初版 `../../monozukuri-hiroba/` と初版のSites URLは変更していない。

## 変換と検証

空白だけの段落を整理し、Jimdoのスタイルとスクリプトを除去。本文を要約・校正・改稿していない。引用符や三つのハイフンが自動変換されないよう、Markdownの句読点変換を無効化。

`tomooooo.json` に元URL、新URL、日付、分類、原本HTMLと本文のSHA-256を記録。

`python scripts/verify-tomooooo.py` で、生成HTMLの本文を元HTML由来のハッシュと比較（空白の差だけ除外）。タイトル、日付、空欄投稿、検索、RSS、旧パス転送、内部リンクも検査する。移行用Pythonスクリプトには beautifulsoup4 と markdownify が必要。通常のAstro起動・ビルドでは不要。

移行前の改訂版はGitタグ `pre-tomooooo-migration-2026-11-05`、初期見本は `archive/sample-works/` に保存。
